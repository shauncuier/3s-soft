# Logos

- `3s-soft-logo.webp`: the primary lockup (300×300). It shows "3S" with the green-over-charcoal S, and "SOFT" letter-spaced below.
  - Colours: green `#2f8c44` (`brand-green`) and charcoal `#585557` (`brand-charcoal`), on a white ground.
  - Use it in the header at 40–48px tall, in the footer, and on OG images.
- `3s-soft-icon-512.png`: the square app and favicon icon. Use it for touch icons, the web manifest and social avatars.
- **Clear space:** at least the height of the "S" stroke on every side.
- **Dark theme:** there is no reversed logo yet. In dark mode, show the mark on a small white tile (`radius-md`, padding `space-2`), because the file has a white ground. Replace this once a reversed SVG exists.
- **Never** redraw, recolour, stretch, add effects, or rebuild the mark from type.
- **Wanted:** an SVG master and a reversed (light-on-dark) version from the original source file.
